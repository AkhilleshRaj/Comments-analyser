# Comments-Analyser  
## Sentiment Analysis using Supervised Learning  

---

## 📌 Project Overview  
This project focuses on classifying user reviews into three categories:  
- Positive (Good)  
- Negative (Bad)  
- Neutral  

It uses supervised machine learning algorithms to analyze text data and predict sentiment.

---

## 🎯 Objective  
- To build a model that can automatically classify reviews  
- To compare performance of different supervised learning algorithms  
- To understand text preprocessing and feature extraction techniques  

---

## 📊 Dataset  
The dataset consists of text reviews and their corresponding sentiment labels.

---

## ⚙️ Methodology  

### 1. Data Preprocessing  
- Convert text to lowercase  
- Remove punctuation  
- Remove stopwords  
- Tokenization  

### 2. Feature Extraction  
- Bag of Words (BoW)  
- TF-IDF  

### 3. Model Selection  
- Logistic Regression  
- Naive Bayes  
- Support Vector Machine (SVM)  

### 4. Training & Testing  
- Train-Test Split (80:20)  
- Model trained on labeled data  

### 5. Evaluation Metrics  
- Accuracy  
- Precision  
- Recall  
- F1-score  

---

## 🛠️ Technologies Used  
- Python  
- Pandas  
- NumPy  
- Scikit-learn  
- NLTK / spaCy  

---

## 📥 Expected Output  
**Input:** The product quality is decent  
**Output:** Neutral
